# 王座下的封印：JRPG 原型

以「飛碟球門派大挑戰」的故事延伸製作的瀏覽器回合制 JRPG。

## 開始遊玩

直接用瀏覽器開啟 `index.html` 即進入「迎戰 Ken13」序幕，或在專案資料夾啟動靜態伺服器：

```powershell
python -m http.server 8001
```

接著瀏覽 <http://127.0.0.1:8001>。

## 遊戲內容

- Terry、Migie、jeRy 組成三人隊伍。
- 戰鬥狀態卡會顯示三位隊員的像素立繪與即時 HP／MP。
- 以普通攻擊、角色技能和防禦指令進行回合制戰鬥。
- 戰鬥畫面有 Ken13 魔王立繪（`assets/ken13-boss.png`）、復活後的紫焰暴走立繪（`assets/ken13-awakened.png`）、魔力核心，以及攻擊、招式與受擊動畫。
- 每次發動普通攻擊後有 20% 機率隨機習得一項新技能，每人最多習得三項，習得時頭上會出現驚嘆號；技能由角色各自記錄，不同角色可習得相同技能，並保留至後續戰鬥，重新開始旅程則重置。
- 新技能包括「二連擊」（MP 15，兩次各 10-15 傷害）、「續力斬」（MP 15，25 傷害）及「猜猜拳」（MP 5，選剪刀、石頭或布與對手猜拳）。
- 每次旅程有補血藥（HP +20）與補魔藥（MP +30）各兩個；戰鬥中可對勇者或敵人使用道具，即使資源已滿也能使用，但不會超過上限，且會消耗一個回合。敵人的 MP 上限與初始值等於 HP，第三回合範圍攻擊會消耗 15 MP。初始道具用完後可在示範商店選購，每個 NT$10；不會實際扣款。
- 依序迎戰魔王 Ken13、魔力核心，以及復活後的 Ken13。
- 每場勝利後會在短暫提示後自動推進至下一段劇情；最後一戰勝利後自動進入第一章結局。
- 插圖素材存放於 `assets/`；遊戲為純前端原型，不需安裝套件或建立帳號。
